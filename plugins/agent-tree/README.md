# agent-tree

A Claude Code mod that puts the savvy-progress agents panel at the top of the filetree file tree, so both live in one side pane. Running, finished and planned subagents are drawn above the tree; when savvy-progress would open its own Agents pane (auto-open or /agents-info), the file tree opens instead. Needs the savvy-progress and filetree mods installed. Drawing code is copied from savvy-progress by johnnyvizz (MIT).

## Install

Needs two other mods: savvy-progress (from this repository) and [filetree](https://github.com/data-goblin/claude-code-filetree) by data-goblin. Install steps are in the [repository README](../../README.md).
